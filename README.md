# m3u

`taiwan.m3u` 是台灣電視頻道的 Extended M3U 清單。播放能力尚未測試；格式通過不代表來源在線、具備觀看授權，或每款播放器都支援。

## 靜態檢查

使用 Python 3.9 以上版本，不需要安裝額外套件。在儲存庫根目錄執行：

```sh
python tools/validate_m3u.py taiwan.m3u
python -m unittest discover -s tests -v
```

Windows 可將 `python` 換成 `py -3`。工具只讀取檔案，不修改清單、不連線、不列印完整 URL，避免把網址內的權杖帶進檢查紀錄。結束碼 0 表示這套靜態規則通過，1 表示內容問題，2 表示檔案讀取或 UTF-8 解碼失敗。警告需要人工確認，但不改變結束碼。

檢查範圍包含 UTF-8、檔首 `#EXTM3U`、`#EXTINF` 的時長與雙引號屬性、名稱、引號外的分隔逗號、缺少 URL、孤立 URL、重複 URL、空白及 URL 基本結構。未知的 `#EXT` 擴充指令只提出警告，不宣稱已驗證其語意。這是網路串流頻道清單的檢查器，不是涵蓋所有 M3U 方言或 HLS 媒體清單標籤的通用驗證器。

## 清單維護

每筆頻道保留原本的名稱、`group-title`、其他屬性與順序；同名但 URL 不同的來源是備援，不能只依名稱刪除。URL 比較只去除行首尾空白，不更改大小寫、參數順序、路徑或權杖。即使網址看起來相似，也不假設網域與 IP 指向相同來源。

只有頻道中繼資料與去除首尾空白後的 URL 都相同，才移除後面重複的紀錄，保留第一筆。相同 URL 但名稱或分組不同時，驗證工具仍會回報重複，請人工確認用途，不應直接刪除。工具沒有自動修正功能。

儲存為 UTF-8 無 BOM，LF 與 CRLF 都可；保留檔尾換行。`group-title` 內原有的逗號和 `#genre#` 位於雙引號內，視為屬性文字，不拆分或重命名。中文及 emoji 原樣保留；不同播放器的字型與分組呈現仍需實機確認。

## 實際播放測試

本次沒有執行網路連線或播放測試，所有串流均為「尚未測試」。要確認播放，需在實際使用的網路及播放器（例如 VLC）載入清單，逐筆確認畫面、聲音、持續播放與備援來源，並記錄測試時間、播放器版本、網路環境和結果。RTMP 支援、來源權杖期限、地區限制及授權條件都可能影響結果；HTTP 成功回應或一次成功播放不能保證後續持續可用。測試失敗也不要直接刪除來源，應先記錄原因再判斷。
